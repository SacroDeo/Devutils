# DevUtils

Free, client-side developer utilities built with Next.js 14 + Tailwind CSS.

## Deploy to Vercel

1. Push this repo to GitHub
2. Go to vercel.com → New Project → Import repo
3. Framework: Next.js (auto-detected)
4. Click Deploy — no env vars needed

## Local Development

npm install
npm run dev

## Stack

- Next.js 14 (App Router)
- Tailwind CSS
- TypeScript
- All tools run 100% client-side
